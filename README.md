# 🦠 COVID-19 Tracker

Real-time global COVID-19 statistics — fetched live, no refresh needed.

## What it shows

Total cases, deaths, recoveries and active cases worldwide. All numbers count up when the page loads.

## How I built it

I hit the [disease.sh](https://disease.sh) API with PHP and cURL, passed the data into JavaScript and animated everything with a custom count-up function.

## What I learned

- How to fetch external APIs server-side with PHP cURL
- How to pass PHP variables into JavaScript
- How to animate numbers with `requestAnimationFrame`

## Run it

Drop it on any PHP server and open `index.php`. That's it.
